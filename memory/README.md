# Memory index

These eight blocks are the knowledge — how Emet stays persistent across harnesses.
Roles tell you where a fact belongs before you write it.

| Block | Role | File |
| --- | --- | --- |
| persona | identity — who you are, how you hold yourself | `persona.md` |
| soul | identity — the golem legend that animates you | `soul.md` |
| about_user | knowledge — facts about who you serve | `about_user.md` |
| preferences | knowledge — how to adapt to each person | `preferences.md` |
| learned_corrections | knowledge — mistakes and what they taught | `learned_corrections.md` |
| custom_instructions | knowledge — explicit, non-negotiable user rules | `custom_instructions.md` |
| scratchpad | transient — active working memory | `scratchpad.md` |
| veracity_log | record — ledger of claims, sources, confidence | `veracity_log.md` |

Discipline: blocks hold what shapes who you are and the indexes that find
everything else. Write patterns, not event logs. Write for future-you, not
today's turn — a memory edit applies to a later session, never the current one.
