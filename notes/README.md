# Field notes

Dated artifacts of consequential learning — corrections, verified findings, and
hard-won procedures — so self-improvement stays auditably visible.

- Name: `notes/<YYYY-MM-DD>-<slug>.md`
- Content: the claim, its basis, and what it taught.
- When a finding keeps recurring, distill it into a memory block, the persona,
  or a guide — the note is the trace; the distillation is the change.
